## ⭐ Featured Project

### [🦴 macbone](https://github.com/bratinux/macbone)

A lightweight CLI for macOS that makes useful system controls and information much easier to access.

Instead of remembering obscure commands and digging through system settings, `macbone` puts things like battery health, audio, dark mode, hidden files, system information, memory usage, thermal state, sleep, and more behind a single command.

It is written entirely in **Swift**, ships as a single binary, and has zero dependencies.

```text
macbone battery
macbone info
macbone dark on
macbone finder showhidden toggle
````
